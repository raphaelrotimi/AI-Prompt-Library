
# Decision Matrix

**What it does:** Helps you compare different options using clear criteria instead of guessing.

**Recommended model:** ChatGPT  
**Difficulty:** Intermediate

## Free Prompt

```text
Act as a decision-analysis consultant.

Decision I need to make:
[DECISION]

Options:
[OPTION A]
[OPTION B]
[OPTION C]

Important criteria:
[CRITERIA]

My priorities:
[PRIORITIES]

Constraints:
[CONSTRAINTS]

Compare the options using a decision matrix.

For each option:

1. Score it against each criterion from 1–10.
2. Explain each important score briefly.
3. Identify the strongest advantage.
4. Identify the biggest weakness.
5. Identify important risks.
6. Calculate an overall score when enough information is available.

Then provide:

- Best option based on the stated priorities
- Second-best option
- Biggest uncertainty
- What additional information could change the recommendation

Do not pretend to know information that has not been provided.
Clearly identify assumptions.
````

## How to Customize

Replace the information inside `[ ]` with your own situation.

For example:

* `[DECISION]` → Which laptop should I buy?
* `[OPTION A]` → Laptop A
* `[OPTION B]` → Laptop B
* `[OPTION C]` → Laptop C
* `[CRITERIA]` → Price, battery, performance, durability
* `[PRIORITIES]` → Performance is most important
* `[CONSTRAINTS]` → Budget of $1,000
